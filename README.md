# 学校予定共有ボード (School Schedule Board)

Google Apps Script (GAS) と Google スプレッドシートを活用した、小中高校・特別支援学校向けの軽量・高信頼な予定・タスク共有ボードです。

---

## 1. アプリ概要

一般的なカレンダーとは異なり、**「学校で現在何が動いているか（今日・今週・今月・年間）」**を一目で把握するための共有ボードです。

### 主な特徴
- **シンプルな1画面構成**: 「今日」「今週」「今月」「年間」「＋追加」の直感的な操作体系
- **安心の変更履歴管理**: 予定の修正・追記・状態変更のすべてを「誰が・いつ・何をしたか（変更前・変更後）」として自動記録
- **追記と修正の明確な分離**: 既存の本文を壊さずに進捗メモを積み重ねられる「追記」機能
- **誤削除の防止**: 完全削除機能を持たず、「完了」「中止」「取消」として履歴を残しつつ落ち着いたトーンで表示
- **スマートフォン最適化**: 画面幅320pxの最小端末でも横スクロールなしで快適操作、44px以上の押しやすいタップ領域
- **学校現場専用用語**: IT専門用語（スプリント、バックログ等）を一切排除し、誰でも迷わず利用可能
- **高信頼性・並行性**: Google Apps Script の `LockService` による二重登録防止・連番採番・トランザクション保証

## 3. Google Sheets 構成

本システムは Google スプレッドシート内の以下の3つのシートを使用します。シートが存在しない場合は自動作成されます。

### 3.1 `Tasks` シート (予定データ)
| 列 | 列名 | 内容 | 例 |
| :--- | :--- | :--- | :--- |
| A | `taskId` | 連番ID | `TASK-20261003-0001` |
| B | `title` | 予定タイトル | `学芸会プログラム印刷` |
| C | `description` | 予定の内容・詳細 (複数行可) | `印刷室の輪転機で500部印刷` |
| D | `periodType` | 予定時期区分 | `今日`, `今週`, `今月`, `日付指定`, `年間`, `未定` |
| E | `specifiedDate`| 日付指定時の日付 (YYYY-MM-DD) | `2026-10-15` |
| F | `status` | 進行状態 | `検討中`, `進行中`, `保留`, `完了`, `中止`, `取消` |
| G | `assignee` | 担当教職員名 | `教務主任` |
| H | `createdBy` | 登録教職員名 | `教頭` |
| I | `createdAt` | 登録日時 (JST) | `2026/10/03 21:00` |
| J | `updatedBy` | 最終更新者名 | `校長` |
| K | `updatedAt` | 最終更新日時 (JST) | `2026/10/03 21:30` |

### 3.2 `History` シート (変更履歴)
| 列 | 列名 | 内容 | 例 |
| :--- | :--- | :--- | :--- |
| A | `historyId` | UUID | `uuid-xxxx-xxxx` |
| B | `taskId` | 対象予定ID | `TASK-20261003-0001` |
| C | `timestamp` | 操作日時 (JST) | `2026/10/03 21:30` |
| D | `actor` | 操作者名 | `校長` |
| E | `actionType` | 操作種別 | `新規登録`, `修正`, `追記`, `状態変更` |
| F | `fieldName` | 変更項目名 | `タイトル`, `状態`, `追記`, `全体` 等 |
| G | `beforeValue` | 変更前の値 | `進行中` |
| H | `afterValue` | 変更後の値 | `完了` |
| I | `comment` | 備考・追記内容 | 追記本文や自動生成サマリー |

### 3.3 `Members` シート (教職員名簿)
| 列 | 列名 | 内容 | 初期値の例 |
| :--- | :--- | :--- | :--- |
| A | `memberId` | メンバーID | `MEM-0001` |
| B | `name` | 教職員氏名・役職 | `校長`, `教頭`, `教務主任` 等 |
| C | `active` | 在籍フラグ (`TRUE`/`FALSE`) | `TRUE` |
| D | `sortOrder`| 表示順序 (数値) | `1`, `2`, `3` |

## 4. 初期設定手順 (非エンジニア向け)

Google アカウントがあれば、約3分で利用開始できます。

1. **Google スプレッドシートを新規作成**:
   - Google ドライブで「新規」→「Google スプレッドシート」を作成します。
   - スプレッドシート名は「学校予定共有ボード」等、任意の名前で構いません。
2. **Apps Script エディタを開く**:
   - スプレッドシートのメニューバーから「拡張機能」→「Apps Script」をクリックします。
3. **コードの配置**:
   - `src/Code.js` の内容をコピーし、Apps Scriptの `コード.gs` に貼り付けます。
   - `src/Logic.js` の内容をコピーし、Apps Scriptで「ファイルを追加」→「スクリプト」を作成して貼り付けます。
   - `src/index.html` の内容をコピーし、Apps Scriptで「ファイルを追加」→「HTML」を作成し `index` という名前で貼り付けます。
4. **初期化の実行**:
   - エディタ上部の関数プルダウンから `initSheets` を選択し、「実行」をクリックします。
   - ※ 初回のみ権限承認ポップアップが表示されますので、「詳細を表示」→「安全ではないページに移動」をクリックして許可してください。
   - 実行が完了すると、スプレッドシートに `Tasks`, `History`, `Members` の3シートが自動生成され、標準役職（校長、教頭、教務主任、学年主任、養護教諭、事務職員）が登録されます。

## 5. Webアプリのデプロイ方法

1. Apps Script エディタ右上の「デプロイ」→「新しいデプロイ」をクリックします。
2. 「種類の選択」歯車アイコンから「ウェブアプリ」を選択します。
3. 以下の設定を行います：
   - **説明**: `公開バージョン1` (任意)
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員` (または組織内のユーザー)
4. 「デプロイ」をクリックします。
5. 表示された **「ウェブアプリの URL」** をコピーします。
6. このURLを学校内の教職員（PC・スマートフォン）に共有します。ログイン不要ですぐにボードが開きます。

## 6. 教職員（Members）の追加・編集方法

教職員の異動や追加は、スプレッドシートの `Members` シートから直接行えます。
- **追加**: 新しい行に `MEM-0007`、`氏名（または役職）`、`TRUE`、`表示順（数値）` を入力します。
- **異動・非表示**: 異動した職員の `active` 列を `FALSE` に変更すると、アプリのプルダウン選択肢から自動的に非表示になります（過去の履歴データはそのまま保持されます）。

## 7. 利用方法

### 7.1 メイン画面と主要5操作
- **今日**: 今日の予定（「今日」指定または指定日が本日のもの）を表示
- **今週**: 今週の予定（月曜日〜日曜日）を表示
- **今月**: 今月の予定（1日〜末日）を表示
- **年間**: すべての予定を一覧表示
- **＋ 予定を追加**: 新規登録モーダルを開く

### 7.2 予定カードの操作
- **追記**: 既存の本文を変更することなく、進捗報告や連絡事項をタイムスタンプ付きで追加します。カード上にも追記履歴が表示されます。
- **修正**: タイトル、予定時期、指定日、内容、担当者を変更します。変更差分はすべて自動的に履歴へ記録されます。
- **状態変更**: 「検討中」「進行中」「保留」「完了」「中止」「取消」へワンタップで遷移します。
- **履歴**: 登録から現在に至るまでの「誰が・いつ・何をしたか」の完全なタイムラインを確認できます。

## 8. テスト方法

本プロジェクトには、GAS環境を模倣したローカル自動テストスイートが付属しています。

```bash
# 全テストスイート (Level 1〜Level 4、全59項目) の一括実行
node test/run-all-tests.js
```

すべてのテスト項目（構文チェック、期間境界値テスト、バックエンドAPI・排他ロックテスト、人間シナリオテスト、UX10問テスト、レスポンシブ検証）が PASS することを確認できます。
